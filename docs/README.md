# Tài liệu Meloo

Tài liệu môn học, viết bằng tiếng Việt. Quy ước viết (mã định danh, văn phong, mẫu, PlantUML) nằm trong skill `meloo-docs` (`.claude/skills/meloo-docs/SKILL.md`).

| Thư mục | Nội dung |
|---|---|
| `business/` | Bài toán, personas, đối thủ, khảo sát, beta, kế hoạch khởi nghiệp |
| `srs/` | `01-srs.md` (FR/NFR), `02-business-rules.md` (BR-01…BR-29), `03-glossary.md`, `usecases/` |
| `architecture/` | `01-architecture.md`; `adr/` (ADR-0xx); `data/` (ERD, từ điển dữ liệu, sự kiện miền) |
| `uml/` | Sơ đồ PlantUML (`.puml` + `.png`): use case, lớp, tuần tự, hoạt động, trạng thái, C4, triển khai |
| `test/` | Test plan, báo cáo kiểm thử, kiểm thử tải, UAT |
| `process/` | Quy trình làm việc, harness agent, sprint review và retro |
| `runbooks/` | Hướng dẫn vận hành: hạ tầng AWS, deploy, xử lý sự cố |
| `legal/` | Chính sách quyền riêng tư, điều khoản sử dụng, xóa dữ liệu |
| `submissions/` | Bản đã nộp cho môn học |
| `security/` | Mô hình mối đe dọa, kết quả rà bảo mật |
| `manual/` | Hướng dẫn sử dụng và triển khai |

`docs/srs/02-business-rules.md` là nguồn sự thật cho quy tắc nghiệp vụ. Thư mục còn trống giữ chỗ bằng `.gitkeep`; ticket đầu tiên thêm file vào thì xóa `.gitkeep` đó.
