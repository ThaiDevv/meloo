# Spike

Code thử nghiệm để trả lời một câu hỏi kỹ thuật trước khi làm thật (VD SPK-01: chọn nguồn nhạc Deezer hay iTunes).

- Mỗi spike một thư mục `spikes/<mã ticket>-<tên ngắn>/` có `README.md` ghi câu hỏi, cách thử, kết quả và kết luận.
- Kết luận quan trọng được chép thành ADR trong `docs/architecture/adr/`.
- Code ở đây không đưa vào production và không được backend hay frontend import.
